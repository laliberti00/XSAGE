## Legenda
- **Metriche**: CatMRR/CatNDCG = match-categoria (micro); R20/NDCG20 = item-recall; JS = calibrazione vs utente; LT20 = coda-lunga; Coverage = catalogo servito; Gini = (dis)uguaglianza esposizione.
- **Metodi**: BASE = backbone nudo; SIT = +X-SAGE situazionale; Steck-a = calibrazione greedy [Steck 2018] (LT/Cov/Gini non calcolate → 0); Steck-b = bias categoria statico; UNI_glob/mean = neutri.
- **STAT SIT−BASE**: t-test appaiato cross-seed (su ml1m SD≈0 → clustering deterministico, t enorme: vale il bootstrap) + bootstrap per-richiesta [CI95%] p + TOST non-degrado R@20.
